# Data files not included

The following file categories were intentionally excluded from this public GitHub repository:

- Processed event-level participant tables, including `outputs/events_metadata*.csv`.
- Event sequence arrays, including `outputs/events_sequences.npz`.
- Train/test split files under `outputs/splits/`.
- Prediction-level model outputs under `outputs/results/`.
- Supplementary experiment subject-level and prediction-level outputs.
- AZT1D extracted or subject-level processed files.

These files may contain de-identified participant-level biomedical variables or raw-like derived information. Deposit them separately only after confirming that redistribution is allowed by the original dataset terms and any applicable institutional requirements.
